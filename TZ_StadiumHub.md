# ТЗ: StadiumHub — Платформа бронирования спортивных объектов

## 1. ОБЩАЯ ИНФОРМАЦИЯ

**Название:** StadiumHub  
**Платформа:** Web (первая версия) → Mobile (вторая версия)  
**Стек:** ASP.NET Web API (.NET 9) + PostgreSQL + React/Blazor  

---

## 2. РОЛИ СИСТЕМЫ

### 2.1 User (Пользователь)
- Регистрация/авторизация (email + пароль)
- Просмотр профиля, редактирование данных
- Поиск стадионов на карте с фильтрами
- Просмотр детальной информации о стадионе
- Бронирование стадиона с выбором даты/времени
- Онлайн оплата (полная/частичная предоплата)
- История бронирований
- Отмена бронирования (с условиями возврата)
- Создание встречи (игры) на забронированное время
- Приглашение других пользователей на встречу
- Принятие/отклонение приглашений
- Просмотр своих встреч
- Написание отзывов и выставление рейтинга
- Просмотр истории платежей
- Уведомления (новые приглашения, напоминания)
- Добавление стадионов в избранное
- Жалобы на отзывы/стадионы

### 2.2 Stadium Owner (Владелец стадиона)
- Регистрация/авторизация
- Добавление стадиона (название, адрес, координаты, описание)
- Выбор вида спорта (футбол, волейбол, баскетбол, теннис, киберспорт)
- Загрузка фото стадиона (до 10 шт)
- Настройка расписания работы (дни недели, часы)
- Установка цены за час
- Указание доп. услуг (аренда инвентаря, раздевалки, душ, парковка)
- Блокировка времени (техобслуживание, личные нужды)
- Редактирование/удаление своих стадионов
- Просмотр всех бронирований в календаре
- Статистика доходов (по дням/месяцам)
- Подтверждение/отмена бронирований (опционально)
- Настройка правил отмены и возврата
- Просмотр отзывов о стадионе
- Ответы на отзывы

### 2.3 Admin (Администратор)
- Просмотр всех пользователей
- Блокировка/разблокировка пользователей
- Просмотр всех стадионов
- Модерация новых стадионов (одобрение/отклонение)
- Удаление стадионов
- Просмотр жалоб (на пользователей, стадионы, отзывы)
- Обработка жалоб (удаление контента, блокировка)
- Просмотр всех бронирований
- Статистика платформы (регистрации, брони, доходы, активность)
- Управление видами спорта
- Просмотр логов системы

## 3. ФУНКЦИОНАЛЬНЫЕ МОДУЛИ

### 3.1 Авторизация и регистрация
- Регистрация через email + пароль
- Выбор роли при регистрации (User / Stadium Owner)
- Подтверждение email (опционально)
- Вход через JWT токены
- Восстановление пароля
- Личный кабинет с редактированием данных
- Загрузка аватара
- Смена пароля

### 3.2 Карта и поиск стадионов
- Интерактивная карта (Google Maps / Yandex Maps)
- Маркеры стадионов с краткой информацией
- Фильтры:
  - Вид спорта
  - Цена (диапазон)
  - Рейтинг
  - Дата и время доступности
  - Расстояние от пользователя
  - Доп. услуги (парковка, душ и т.д.)
- Список стадионов (альтернативный вид)
- Сортировка (по цене, рейтингу, расстоянию)
- Поиск по названию/адресу

### 3.3 Страница стадиона
- Галерея фото
- Название, адрес, описание
- Вид спорта
- Цена за час
- Рейтинг и количество отзывов
- Расписание работы
- Доп. услуги
- Кнопка "Забронировать"
- Кнопка "В избранное"
- Список отзывов с фильтрацией и сортировкой
- Кнопка "Пожаловаться"

### 3.4 Бронирование
- Выбор даты в календаре
- Показ доступных временных слотов
- Выбор времени начала и конца
- Расчет стоимости автоматически
- Доп. опции (аренда инвентаря)
- Итоговая стоимость
- Переход к оплате
- Подтверждение бронирования
- Email/уведомление после бронирования
- История бронирований пользователя
- Статусы: ожидает оплаты, оплачено, завершено, отменено

### 3.5 Оплата
- Интеграция платежного шлюза (Stripe/Yookassa/PayPal)
- Полная предоплата / частичная предоплата
- Сохранение истории платежей
- Статусы: pending, paid, failed, refunded
- Возврат средств при отмене (по правилам владельца)
- Квитанции на email

### 3.6 Встречи (игры)
- Создание встречи на основе бронирования
- Поля:
  - Название встречи
  - Описание
  - Вид спорта
  - Максимальное количество игроков
  - Публичная/приватная
- Приглашение пользователей:
  - По email
  - По username
  - Поиск в системе
- Список участников
- Статусы приглашений: отправлено, принято, отклонено
- Уведомления участникам
- Отмена встречи
- Просмотр деталей встречи

### 3.7 Отзывы и рейтинг
- Написание отзыва после завершения бронирования
- Рейтинг от 1 до 5 звезд
- Текстовый комментарий
- Загрузка фото к отзыву (опционально)
- Редактирование/удаление своего отзыва
- Ответ владельца на отзыв
- Жалобы на отзывы (спам, фейк, оскорбления)
- Модерация отзывов админом
- Средний рейтинг стадиона

### 3.8 Уведомления
- Email уведомления:
  - Подтверждение регистрации
  - Подтверждение бронирования
  - Напоминание о бронировании (за 24 часа)
  - Приглашение на встречу
  - Принятие/отклонение приглашения
  - Новый отзыв на стадион (владельцу)
  - Изменение статуса жалобы
- In-app уведомления (звоночек в интерфейсе)
- Настройки уведомлений (включить/выключить типы)

### 3.9 Панель владельца стадиона
- Список своих стадионов
- Добавление нового стадиона
- Редактирование стадиона
- Календарь бронирований
- Статистика:
  - Количество бронирований
  - Общий доход
  - График загруженности
  - Средний рейтинг
- Блокировка времени вручную
- Управление ценами (скидки, спецпредложения)

### 3.10 Админ-панель
- Дашборд с общей статистикой:
  - Количество пользователей
  - Количество стадионов
  - Количество бронирований
  - Общий доход платформы
  - Активные пользователи
- Управление пользователями:
  - Список с фильтрами
  - Просмотр деталей
  - Блокировка/разблокировка
- Управление стадионами:
  - Модерация новых
  - Просмотр/удаление
- Жалобы:
  - Список жалоб
  - Просмотр деталей
  - Принятие решения (удалить контент, заблокировать пользователя, отклонить жалобу)
- Управление видами спорта (добавление новых)
- Логи системы

### 3.11 Компьютерные клубы (Киберспорт) 🎮

#### 3.11.1 Для владельца компьютерного клуба
**Добавление клуба:**
- Название клуба
- Адрес и координаты на карте
- Описание
- Загрузка фото клуба (зал, ПК, VIP-зоны)
- Выбор категории: киберспорт
- Общее количество ПК
- Наличие VIP-зоны (да/нет)
- Наличие консольной зоны (да/нет)
- Расписание работы

**Настройка рабочих мест (ПК):**
- Добавление каждого ПК отдельно
- Номер места (1, 2, 3...)
- Тип места:
  - Standard (обычное)
  - VIP (улучшенное, отдельная зона)
  - Console (PlayStation/Xbox)
- Характеристики ПК:
  - Процессор (CPU)
  - Видеокарта (GPU)
  - Оперативная память (RAM)
  - Монитор (диагональ, Гц)
  - Периферия (мышь, клавиатура, наушники)
- Цена за час для этого места
- Статус: доступно/не доступно

**Список поддерживаемых игр:**
- Добавление игр которые установлены в клубе:
  - CS2 (Counter-Strike 2)
  - Dota 2
  - Valorant
  - League of Legends
  - Fortnite
  - Apex Legends
  - Overwatch 2
  - FIFA/FC
  - GTA V
  - Minecraft
  - И другие...
- Загрузка иконок игр
- Отметка установлена ли игра

**Управление бронированиями:**
- Календарь с визуализацией занятых ПК
- Просмотр бронирований по датам
- Фильтр по номеру ПК
- Блокировка конкретных ПК (ремонт, обслуживание)
- Статистика загруженности каждого места
- Статистика доходов по типам мест (standard/vip)

**Дополнительные услуги:**
- Напитки и еда (энергетики, снеки)
- Аренда гарнитуры премиум-класса
- Турниры и мероприятия
- Трансляции на большом экране

#### 3.11.2 Для пользователя (игрока)
**Поиск компьютерных клубов:**
- Фильтр "Киберспорт" на карте
- Показ клубов с иконкой геймпада
- Фильтры:
  - Цена (диапазон)
  - Наличие конкретной игры (выбор из списка)
  - Тип мест (standard/vip/console)
  - Характеристики ПК (мин. GPU, RAM)
  - Рейтинг клуба
  - Расстояние

**Страница компьютерного клуба:**
- Фото клуба
- Название, адрес, описание
- Список установленных игр с иконками
- Количество доступных ПК
- Схема зала (визуализация расположения ПК)
- Список всех рабочих мест с характеристиками:
  - Номер места
  - Тип (standard/vip/console)
  - Спецификации (CPU, GPU, RAM, монитор)
  - Цена за час
  - Статус (свободно/занято)
- Рейтинг и отзывы
- Расписание работы
- Дополнительные услуги

**Бронирование компьютерного клуба:**

**Вариант 1: Бронирование конкретных ПК (стандарт)**
- Выбор даты и времени
- Показ схемы зала со всеми ПК
- Цветовая индикация:
  - 🟢 Зеленый — свободно
  - 🔴 Красный — занято
  - 🟡 Желтый — выбрано пользователем
- Клик на номер ПК → добавление в корзину
- Можно выбрать несколько ПК (для игры с друзьями)
- Автоматический расчет стоимости
- Фильтр по типу места (показать только VIP)
- Оплата онлайн

**Вариант 2: Полное бронирование клуба**
- Для турниров или больших встреч
- Выбор даты и времени
- Бронирование всего зала целиком
- Специальная цена для полного бронирования

**Создание киберспортивной встречи:**
- После бронирования ПК можно создать встречу
- Поля:
  - Название встречи (например: "CS2 5v5 турнир")
  - Описание
  - Выбор игры из списка установленных
  - Формат игры:
    - Casual (просто поиграть)
    - 1v1 (дуэль)
    - 2v2
    - 5v5 (команда на команду)
    - Tournament (турнир с несколькими раундами)
  - Максимальное количество игроков
  - Публичная/приватная
  - Уровень навыка (новичок/средний/про)
- Приглашение игроков:
  - По email/username
  - Из друзей
  - Публичное объявление (открытая встреча)
- Автоматическое распределение по командам (для 5v5)
- Список участников с их ролями (Capitan, Support и т.д.)

**Присоединение к публичным встречам:**
- Поиск открытых встреч в клубах
- Фильтры по игре, формату, уровню
- Быстрое присоединение одним кликом
- Чат участников (до встречи)

**После игры:**
- Написать отзыв о клубе
- Оценить качество ПК
- Оценить атмосферу
- Загрузить скриншоты/видео

#### 3.11.3 Особенности для киберспорта
**Турниры:**
- Создание турнирной сетки
- Поддержка форматов: Single Elimination, Double Elimination, Round Robin
- Автоматическое создание матчей
- Ведение счета
- Таблица лидеров

**Стриминг:**
- Интеграция с Twitch/YouTube для трансляций
- QR-код для просмотра стрима зрителями

**Статистика игрока:**
- История сыгранных матчей
- Любимые игры
- Win Rate (процент побед)
- Средний KDA (для шутеров)
- Часы игры

**Рейтинг киберспортсменов:**
- ELO-система
- Ранги (Bronze, Silver, Gold, Platinum, Diamond)
- Топ игроков по играм
- Достижения и бейджи

## 4. СТРУКТУРА БД (основные таблицы)

### Users
- Id (UUID)
- Email (unique)
- PasswordHash
- Role (admin, stadium_owner, user)
- FullName
- PhoneNumber
- Avatar (URL)
- IsBlocked
- CreatedAt
- UpdatedAt

### SportTypes
- Id
- Name (футбол, волейбол, баскетбол, теннис, киберспорт)
- Icon (URL)
- IsPhysical (true для спорта, false для киберспорта)

### Stadiums
- Id (UUID)
- OwnerId → Users.Id
- SportTypeId → SportTypes.Id
- Name
- Description
- Address
- Latitude
- Longitude
- PricePerHour
- VenueType (stadium, computer_club) — тип заведения
- IsActive (модерация)
- IsApproved (админ)
- CreatedAt
- UpdatedAt

### ComputerClubSpecs (характеристики компьютерного клуба)
- Id
- StadiumId → Stadiums.Id (используем ту же таблицу для единства)
- TotalPCs (общее количество ПК)
- VIPZoneAvailable (есть ли VIP-зона)
- ConsoleZoneAvailable (есть ли зона с консолями)
- CreatedAt

### PCWorkstations (рабочие места в клубе)
- Id
- ClubId → Stadiums.Id
- WorkstationNumber (номер места: 1, 2, 3...)
- WorkstationType (standard, vip, console)
- Specifications (JSON: CPU, GPU, RAM, Monitor и т.д.)
- PricePerHour (цена за это конкретное место)
- IsAvailable (доступно ли сейчас)

### SupportedGames (поддерживаемые игры в клубе)
- Id
- ClubId → Stadiums.Id
- GameName (CS2, Dota 2, Valorant, League of Legends, Fortnite и т.д.)
- GameIcon (URL)
- IsInstalled (установлена ли игра)

### StadiumPhotos
- Id
- StadiumId → Stadiums.Id
- PhotoUrl
- Order (порядок отображения)

### StadiumSchedules
- Id
- StadiumId → Stadiums.Id
- DayOfWeek (0-6)
- OpenTime
- CloseTime

### StadiumAmenities (доп. услуги)
- Id
- StadiumId → Stadiums.Id
- AmenityType (parking, shower, locker_room, equipment_rental)
- Description
- AdditionalPrice

### Bookings
- Id (UUID)
- StadiumId → Stadiums.Id
- UserId → Users.Id
- BookingDate
- StartTime
- EndTime
- TotalPrice
- PaymentStatus (pending, paid, cancelled, refunded)
- BookingStatus (active, completed, cancelled)
- BookingType (full_venue, specific_pcs) — полное бронирование или конкретные ПК
- CreatedAt

### BookingPCs (забронированные ПК для компьютерных клубов)
- Id
- BookingId → Bookings.Id
- WorkstationId → PCWorkstations.Id
- CreatedAt

### Payments
- Id
- BookingId → Bookings.Id
- Amount
- PaymentMethod (card, paypal, etc)
- TransactionId (внешний ID платежа)
- Status (pending, success, failed, refunded)
- CreatedAt

### Meetings
- Id (UUID)
- BookingId → Bookings.Id
- CreatorId → Users.Id
- Title
- Description
- MaxPlayers
- IsPublic
- GameId → SupportedGames.Id (для киберспорта — какая игра)
- TournamentFormat (casual, 1v1, 2v2, 5v5, tournament) — формат игры
- CreatedAt

### MeetingParticipants
- Id
- MeetingId → Meetings.Id
- UserId → Users.Id
- Status (invited, accepted, declined)
- InvitedAt
- RespondedAt

### Reviews
- Id (UUID)
- StadiumId → Stadiums.Id
- UserId → Users.Id
- BookingId → Bookings.Id (можно оставить отзыв только после брони)
- Rating (1-5)
- Comment
- OwnerResponse (ответ владельца)
- CreatedAt
- UpdatedAt

### ReviewPhotos
- Id
- ReviewId → Reviews.Id
- PhotoUrl

### Reports (жалобы)
- Id
- ReporterId → Users.Id
- EntityType (review, stadium, user)
- EntityId (ID объекта)
- Reason
- Status (pending, resolved, rejected)
- AdminResponse
- CreatedAt
- ResolvedAt

### Favorites
- UserId → Users.Id
- StadiumId → Stadiums.Id
- CreatedAt

### Notifications
- Id
- UserId → Users.Id
- Type (booking_confirmed, meeting_invite, review_received, etc)
- Message
- IsRead
- CreatedAt

### BlockedTimes (блокировка времени владельцем)
- Id
- StadiumId → Stadiums.Id
- BlockDate
- StartTime
- EndTime
- Reason

## 5. API ENDPOINTS (основные)

### Auth
- POST /api/auth/register
- POST /api/auth/login
- POST /api/auth/refresh-token
- POST /api/auth/forgot-password
- POST /api/auth/reset-password

### Users
- GET /api/users/me
- PUT /api/users/me
- POST /api/users/me/avatar
- PUT /api/users/me/password

### Stadiums
- GET /api/stadiums (фильтры, пагинация)
- GET /api/stadiums/{id}
- POST /api/stadiums (owner)
- PUT /api/stadiums/{id} (owner)
- DELETE /api/stadiums/{id} (owner/admin)
- GET /api/stadiums/{id}/available-slots?date=...
- POST /api/stadiums/{id}/favorite
- DELETE /api/stadiums/{id}/favorite

### Bookings
- POST /api/bookings
- GET /api/bookings/my
- GET /api/bookings/{id}
- PUT /api/bookings/{id}/cancel
- GET /api/stadiums/{stadiumId}/bookings (owner)

### Payments
- POST /api/payments/create
- POST /api/payments/confirm
- GET /api/payments/my

### Meetings
- POST /api/meetings
- GET /api/meetings/{id}
- GET /api/meetings/my
- DELETE /api/meetings/{id}
- POST /api/meetings/{id}/invite
- PUT /api/meetings/invitations/{id}/accept
- PUT /api/meetings/invitations/{id}/decline

### Reviews
- POST /api/reviews
- GET /api/stadiums/{id}/reviews
- PUT /api/reviews/{id}
- DELETE /api/reviews/{id}
- POST /api/reviews/{id}/owner-response (owner)

### Reports
- POST /api/reports
- GET /api/reports (admin)
- PUT /api/reports/{id}/resolve (admin)

### Admin
- GET /api/admin/users
- PUT /api/admin/users/{id}/block
- PUT /api/admin/users/{id}/unblock
- GET /api/admin/stadiums
- PUT /api/admin/stadiums/{id}/approve
- PUT /api/admin/stadiums/{id}/reject
- GET /api/admin/statistics

### Notifications
- GET /api/notifications/my
- PUT /api/notifications/{id}/read
- PUT /api/notifications/read-all

### Computer Clubs (Киберспорт)
- POST /api/computer-clubs (создание клуба)
